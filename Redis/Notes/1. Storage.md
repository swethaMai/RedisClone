# Storage.js
## Working
- In-memory key-value store
- includes lazy expiration
### In-memory
- In-memory means data disappears when server stopped
- here stored in Map which exists in RAM (Random Access Memory -> Short-term memory) of machine not disk
- makes operations fast and is perfect for caching, session storage etc.
### key-value store
- Map used to store key-value pair
- key
    - string
    - obtained from RESP `SET` key value or `GET` key value
- value (wrapper object)
    - value : 
        - Buffer -> handles raw binary data 
        - actual stored data
    - expiresAt 
        - timestamp at which key should be expired
        - for TTL
- `store.set(key, { value: Buffer, expiresAt: number | null });` 
{
  value: <Buffer ...>,     // the actual data the user stored
  expiresAt: 1710001234567 // timestamp or null
}
### lazy expiration

## Functions used
### isAlive
- internal function
- process
    1. gets key
    2. checks if exists 
        3. if exists checks if expired
            1. if not expired -> return true
            2. if expired -> return false & delete key-value pair
        4. if doesn't exist -> return false

## Functions exported
### set
- set key to value (actual data, TTL (now() + TTL value))
### get
- get value if alive
### del
- delete key 
    1. if found -> delete and return 1
    2. if not found -> return 0
### exists
1. if alive -> return 1
2. if not alive -> return 0
### cleanup
1. for all values in store (key-value pair)
    1. if now() >= expiresAt -> delete
    2. else no action
